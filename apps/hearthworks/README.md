# Hearthworks marketing site

The independent marketing site for [hearthworks.co](https://hearthworks.co).

This application is intentionally separate from:

- `apps/website` — Hadley’s Kitchen public bakery website
- `apps/platform` — the authenticated Hearthworks product

## Local development

```sh
npm install
npm run dev
```

## Vercel

Create a dedicated Vercel project with `apps/hearthworks` as its Root Directory, then attach `hearthworks.co` and `www.hearthworks.co` to that project.
