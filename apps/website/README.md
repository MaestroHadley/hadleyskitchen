# Hadley's Kitchen Website

Marketing site for Hadley's Kitchen, rebuilt in Next.js for Vercel deployment.

This application is deployed from the `apps/website` Vercel Root Directory and serves `hadleyskitchen.com` and `www.hadleyskitchen.com`.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content updates

Shared copy and links live in `src/content/site.ts`.

Update `orderUrl` there when the external ordering platform is finalized.
